## Ce que fait le code (étape par étape)

### 1. Configuration et chargement du modèle

- Installation des dépendances : `huggingface_hub`, `h5py`, `torch`, `tqdm`, `scipy`.
- Authentification sur Hugging Face (jeton stocké dans les secrets Colab).
- Définition des dépôts :
  - **Données** : `Yousra0x0/validation_20_preprocessed` (20 fichiers `.h5` contenant images + masques).
  - **Modèle** : `hourouu/model4` (poids UNet, fichier `best.pth`).
  - **Résultats** : `Yousra0x0/unet_validation_20` (où seront uploadés les rapports).
- Construction de l’architecture UNetV2 (conv Double + InstanceNorm + skip connections).
- Chargement des poids du modèle (meilleur Dice = 0.9044 sur l’entraînement).
- Modèle mis en mode `eval()` et déplacé sur GPU (CUDA).

### 2. Inférence sur les 20 volumes de validation

- Téléchargement intégral du dataset de validation (snapshot download).
- Pour chaque fichier `.h5` :
  - Lecture de l’image (array 3D, normalisé [0,1]) et du masque réel (binaire).
  - Inférence **slice par slice** (le modèle est 2D) :
    - Chaque coupe est passée dans le réseau → carte de probabilités.
    - Seuillage à 0.5 → prédiction binaire.
  - Reconstitution du volume 3D prédit.
  - Calcul des métriques entre la prédiction et le masque réel.

### 3. Métriques calculées

Pour chaque volume, les indicateurs suivants sont produits :

| Métrique            | Formule / signification |
|---------------------|--------------------------|
| **Dice**            | `2*|P∩T| / (|P|+|T|)` – similarité globale |
| **IoU** (Jaccard)   | `|P∩T| / |P∪T|` |
| **Précision**       | `TP / (TP+FP)` |
| **Rappel** (sensibilité) | `TP / (TP+FN)` |
| **F1**              | Moyenne harmonique précision/rappel |
| **Spécificité**     | `TN / (TN+FP)` |
| **HD95** (95e percentile de Hausdorff) | Distance maximale entre les contours (95%) – mesure la qualité des bords |
| **Erreur volumique** | `|vol_pred - vol_gt| / vol_gt * 100` (en %) |

*P = prédiction, T = vérité terrain, TP/FP/FN/TN = vrais/faux positifs/négatifs.*

### 4. Agrégation des résultats

- Calcul de la moyenne, écart‑type, min, max et médiane pour chaque métrique sur les 20 volumes.
- Création d’un dictionnaire `summary` contenant :
  - Informations générales (modèle, jeu de données, seuil, date)
  - Les 5 statistiques pour chaque métrique.

### 5. Sauvegarde locale et export

Deux fichiers sont générés dans `/content/val_results/` :

- **`validation_results.json`** : structure complète avec le résumé global et les métriques individuelles par patient.
- **`validation_report.txt`** : rapport texte lisible, contenant :
  - En‑tête (date, nombre de volumes, seuil, modèle)
  - Tableau des métriques agrégées
  - Section détaillée pour chaque volume (toutes ses métriques)

### 6. Upload vers Hugging Face

Les deux fichiers sont poussés vers le dataset `Yousra0x0/unet_validation_20` (dossier `/validation/`).  
Un message de commit explicite est ajouté : `Validation UNet — 20 volumes`.
